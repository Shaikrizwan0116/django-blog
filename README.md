## 📘 Project Overview

This project is a complete Django-based blog application developed from scratch. 
It covers the full development lifecycle, starting from project setup and version control configuration to deployment.

The application includes a dynamic homepage with featured and recent blog posts, category-based filtering, and detailed single blog pages. Categories and blog posts are managed through custom dashboards with full CRUD functionality, including automatic slug generation and author assignment.

User authentication and authorization are implemented using Django’s built-in system. The project supports user registration, login, logout, and role-based access control using groups such as Managers and Editors. Each role has specific permissions that control access to dashboards and actions like user management, category management, and post editing.

A commenting system allows authenticated users to interact with blog posts. The application also includes a search feature that enables users to find articles while preserving search terms for better user experience.

Additional features include template inheritance, context processors, custom 404 error handling, static and media file configuration, and social links integration. The project is version-controlled using Git and follows best practices with regular commits and structured pushes.

Finally, the application is deployment-ready, with a complete deployment checklist and configuration for production environments.
